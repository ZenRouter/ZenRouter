# 🌿 Implementation Plan: ZenRoute Rebranding & Visual Redesign

This plan covers the complete rebranding of the project from **9Router** to **ZenRoute**, including vector SVG logo asset generation based on the Matisse-style reference image, color palette modernization (Zen Indigo/Slate Blue + Vermilion Sun Accent), UI dashboard & landing page transformation, configuration updates, and GitHub repository metadata sync via `gh` CLI.

---

## 🎯 Rebranding Specifications

- **Brand Name:** `ZenRoute` (Web / UI / Docs) & `zenroute` (CLI / Package)
- **Tagline:** *"Serene AI Gateway & Intelligent Routing Engine"*
- **Secondary Tagline:** *"Cultivate, prune, and route all your AI models from a single unified gateway."*
- **Visual Identity (Based on Reference 1):**
  - **Main Star/Flower Motif:** Organic 6-lobed cut-out in Zen Slate Blue (`#4A6FA5` / `#5E81AC`) representing multi-provider routing branches.
  - **Zen Sun Motif:** Warm vermilion sun dot (`#E75A38` / `#F05530`) representing the unified gateway core.
- **UI Color System in `src/app/globals.css`:**
  - Update `--color-brand-*` palette to Zen Blue & Slate tones with vermilion secondary accents.
  - Ensure perfect contrast in both Light Mode (clean off-white paper canvas `#FDFCFA`) and Dark Mode (deep zen obsidian `#12161A` / `#1A202C`).

---

## 📋 Actionable Steps

### 1. 🎨 Asset Creation & Logo Generation
- **Create Master Vector SVG:** Create high-precision, optimized SVG reproducing the organic cut-out shape (blue 6-lobed router star + vermilion gateway sun) in `public/favicon.svg` and `public/icons/logo.svg`.
- **Generate PWA & Manifest Icons:** Generate `public/icons/icon-192.svg` and `public/icons/icon-512.svg`.
- **Update Favicon References:** Update `src/app/manifest.js`, `src/app/layout.js`, and generate/replace `src/app/favicon.ico`.
- **System Tray Assets:** Provide updated tray icons in `cli/src/cli/tray/`.

### 2. 🎭 Theme, Color Accent & Tailwind Updates
- **Update CSS Variables (`src/app/globals.css`):**
  - Replace old coral/orange `--color-brand-*` scale (50–900) with modern Zen Slate Blue & Indigo scale.
  - Configure secondary accent tokens for the vermilion sun highlight (`--color-accent-sun: #E75A38`).
  - Update selection backgrounds, focus rings, and scrollbar accents.
- **Update Landing Page Component Accents:**
  - Replace hardcoded orange `#f97815` in `src/app/landing/components/` (Navigation, HeroSection, FlowAnimation, HowItWorks, GetStarted) with dynamic brand tokens (`text-primary`, `bg-brand-500`, `from-brand-600 to-accent-sun`).

### 3. 🖥️ UI Dashboard & Component Rebranding
- **App Configuration (`src/shared/constants/config.js`):**
  - Set `APP_CONFIG.name = "ZenRoute"`
  - Set `APP_CONFIG.description = "Serene AI Gateway & Intelligent Routing Engine"`
  - Update GitHub changelog links and package metadata.
- **Sidebar (`src/shared/components/Sidebar.js`):**
  - Update sidebar logo container to display the new ZenRoute SVG logo.
  - Update application title and version check modals.
- **Header & Footer (`src/shared/components/Header.js`, `Footer.js`):**
  - Update brand headers, breadcrumb labels, and copyright notices.
- **Login & Auth (`src/app/login/page.js`):**
  - Update brand display, tagline, and login prompts.
- **CLI Tool Cards & Topology (`src/app/(dashboard)/dashboard/...`):**
  - Update central topology hub node label to `ZenRoute`.
  - Update helper texts and integration instructions across all tool cards while maintaining backward compatibility.

### 4. ⚙️ Package, CLI & Server Configuration
- **Package Configuration:**
